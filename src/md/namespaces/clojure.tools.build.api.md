`clojure.tools.build.api` provides functions for common Clojure build tasks such as compiling Java sources, copying files and directories, creating JAR and uber-JAR files, and installing to local Maven repositories.

**tools.build is not provided as part of Clojure's standard distribution, and must be included as a [dependency](https://github.com/clojure/tools.build#release-information)**.
